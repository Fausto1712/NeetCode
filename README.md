# NeetCode

LeetCode / NeetCode algorithm practice — Python solutions organized by problem number.

## Overview

| | |
|---|---|
| **Solutions** | ~160 Python files |
| **Language** | Python 3 |
| **Topics** | Arrays, Trees, Graphs, Dynamic Programming, Backtracking, Heaps, Tries, Linked Lists, Binary Search, Intervals, Greedy, Sorting |
| **Templates** | `templates/` — reusable scaffolds for trees, graphs, and tries |

## Structure

```
├── <number>.py          # Solution file per LeetCode problem
├── templates/
│   ├── tree_template.py
│   ├── graph_template.py
│   └── trie_template.py
├── test.py              # Local test runner
└── .vscode/             # Editor settings
```

## Run

```bash
python3 <number>.py
```

No external dependencies required.
